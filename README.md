# KarirAI

AI-Powered Resume & Career Platform untuk pasar Indonesia.

Dibangun dengan Next.js 14 (App Router), Tailwind CSS, Supabase, dan Claude API.

## Getting Started

1. Copy `.env.local.example` ke `.env.local` dan isi kredensial yang dibutuhkan.
2. Install dependencies:

```bash
npm install
```

3. Jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
